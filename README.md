# Petualangan Komposisi - Seni Rupa Kelas 3

Modul belajar HTML interaktif untuk anak kelas 3 tentang komposisi seni rupa.

## Materi

- Keseimbangan dalam benda, lingkungan, dan seni rupa
- Pengertian komposisi dan delapan unsur rupa
- Komposisi simetris, asimetris, dan radial
- Sembilan prinsip seni rupa
- Aktivitas pengamatan dan proyek kolase
- Pengayaan tentang Alma Thomas
- Kuis, soal HOTS, refleksi, glosarium, dan piagam mini

## Fitur

- Efek membalik halaman seperti buku pada komputer
- Tampilan satu halaman yang nyaman pada ponsel
- Mode huruf besar dan pembaca suara
- Kuis interaktif dengan skor
- Jawaban dan kemajuan belajar tersimpan di browser
- Tidak membutuhkan framework atau proses build

## Menjalankan secara lokal

Karena proyek ini menggunakan file statis, jalankan server lokal dari folder proyek. Contoh dengan Python:

```bash
python3 -m http.server 8000
```

Kemudian buka `http://localhost:8000`.

## Mengaktifkan GitHub Pages

1. Buat repository baru di GitHub.
2. Unggah seluruh isi folder ini ke branch `main`.
3. Buka **Settings > Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu simpan.
6. GitHub akan menampilkan alamat situs setelah proses publikasi selesai.

Semua path aset menggunakan path relatif sehingga dapat langsung digunakan pada GitHub Pages.
